
# Project Reflection

## What I Got Wrong at the Start

Initially, I thought that managing shop inventory was mainly about adding products, updating quantities, and generating bills. However, after learning about the incident at Samrat Bazar, I understood that maintaining accurate stock records is also important. A shopkeeper may discover missing products only after several days if stock is not checked regularly.

## What I Would Cut

I would avoid adding too many features at the beginning. Instead, I would focus on the most important functionality: maintaining product records, recording stock movements, and identifying differences between recorded and physical quantities. This would make the application easier to use and test.

## Where AI Helped

AI helped me organize the project requirements, understand how inventory discrepancies can be calculated, plan the documentation, and think about how a CSV-based analysis tool could work.

## Where AI Wasted Time

Some suggestions introduced additional features and complexity before the basic requirements were fully completed. I learned that generated suggestions still need to be checked against the actual project code and the needs of the shopkeeper.

## What I Learned

This project helped me understand that software development should begin with a real problem. A technically working application is not enough if it does not solve the actual user's problem. I also learned the importance of accurate data collection, testing, and understanding the limitations of an application.
